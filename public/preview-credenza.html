❌ The Problem

Test account management was a major source of friction for both manual testers and automation engineers:

  • Hard-coded credentials scattered across multiple repositories
  • No visibility into who was using which accounts
  • Account conflicts causing frequent test failures
  • Manual testers relied on Slack messages and spreadsheets
  • Automation had no programmatic way to request accounts
  • No audit trail to investigate issues

✅ The Solution

Built Credenza with dual access paths:

  • Web Dashboard - Intuitive interface for manual testers to browse, request, and release accounts
  • REST API - Seamless integration for automation with automatic allocation and release
  • Quick Actions - Browse Accounts, My Accounts, API Tokens
  • Administration - User management, force release, region/environment config
  • Audit Trail - Detailed logging for usage analysis
  • Keeper + Okta SSO - Secure token management

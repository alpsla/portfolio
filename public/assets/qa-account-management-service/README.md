# Credenza - Test Account Management

## Overview
Credenza is a centralized test account management platform that eliminates credential chaos across QA automation. It replaces hard-coded credentials scattered across repositories with a unified dashboard for account allocation, usage tracking, and dynamic provisioning.

## The Problem We're Solving

### Before Credenza
- ❌ Hard-coded credentials scattered across repos
- ❌ No visibility into who's using which accounts
- ❌ Account conflicts causing test failures
- ❌ Manual coordination via Slack & spreadsheets
- ❌ No audit trail to track usage or issues
- ❌ Time wasted searching for available accounts

### With Credenza
- ✓ Centralized account management
- ✓ Account usage assignment & coordination
- ✓ Usage control, tracking & reporting
- ✓ Dynamic allocation for any criteria
- ✓ API integration with test suites
- ✓ No more PRs for account maintenance

**Estimated time savings: 30-60 minutes per tester per day**

## Key Features

### Dashboard
- Centralized account management
- Account Usage Assignment to User & Better Coordination
- Usage Control, tracking & Reporting
- Dynamic allocation & multiple account setup for given criteria

### Automation Integration
- API Integration with test suite (quality-engineering-test)
- Keeper integration for secure token management
- POJO models for Account Request
- Test Tear Down and Fail-over handling

### Administration
- User management, and force release of accounts
- Region, Environment, Platform, and Application management
- Account Usage and Request Error details
- Audit Trail details for detailed analysis
- Database browser
- Full API documentation access

## Planned Enhancements
- Account Criteria definitions and support in requests
- Automatic account provisioning for Staging
- Regular Health checks on accounts
- Auto healing of account issues
- Flagging & Reporting of accounts that could not be healed
